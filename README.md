# Network Traffic Analysis

## Description
A network traffic analysis project using Wireshark to identify 
potential security threats on a home network.

## Tools Used
- Wireshark 4.6.4

## Files
- network_capture.pcap — Raw packet capture file
- Network_Traffic_Analysis_Report.docx — Full analysis report
- Screenshots of DNS, HTTP, TCP filters and Statistics

## Findings
- Unencrypted DNS queries detected
- HTTP traffic observed
- Multiple external IP connections documented

## Recommendations
- Use HTTPS only websites
- Use a VPN on public networks
- Enable DNS over HTTPS
